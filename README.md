# Playwright QA Framework

End-to-end test automation framework built with Playwright and TypeScript,
covering UI, API and CI/CD best practices.

## Status

🚧 Work in progress — built step by step as a learning project.

## Tech Stack

- [Playwright](https://playwright.dev/) — browser and API test automation
- [TypeScript](https://www.typescriptlang.org/) — typed JavaScript
- [GitHub Actions](https://github.com/features/actions) — CI/CD pipeline
